## Run locally

Because this is a static site, no build step is required. Open `index.html` directly in a browser, or serve the repository root with any static server.

Example:

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`

## Deploy

This repository is served as a GitHub Pages user site. Deploy by pushing changes to the `main` branch (repository root), which is the Pages source.

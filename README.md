Harold Rosales — Portfolio

This repository contains a simple single-page portfolio site generated from Harold's CV and deployed on GitHub Pages.

Deploy URL:
https://hros18.github.io

How to update
- Edit index.html and styles.css directly in this repository and push changes.
- To replace the profile photo: put an image at assets/profile.svg or replace it with a PNG/JPG at assets/profile.png and update the <img> src in index.html.
- To set your LinkedIn URL: open index.html and replace the href on the element with id="linkedin".

Notes
- The site uses a dark theme and responsive layout.
- GitHub Pages is already enabled for this repo; changes pushed to the default branch (main) will publish automatically.
